# Student Performance Predictor

A Machine Learning project that predicts a student's final marks using:

- Study Hours
- Attendance
- Previous Marks
- Assignment Score

## Machine Learning Model

Multiple Linear Regression

## Dataset

2000 student records.

## Features

Hours
Attendance
Previous Marks
Assignments

## Target

Final Marks

## Evaluation

MAE: 4.25
R² Score: 0.8256

The model explains approximately 82.56% of the variation in final marks.# student-performance-predictor
